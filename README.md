# Arch-bridge

一个面向公众的赵州桥交互科普页面：从现代地图定位开始，逐步提出“为什么要跨河”的工程问题，比较桥型，再把主拱、敞肩小拱、桥面和传力路径一块块建起来。观众可以跟随电影感运镜，也可以随时拖动、缩放和切换观察工具。

![赵州桥交互页面预览](preview.png)

## 体验内容

- **地图定位**：中国 → 河北 → 石家庄 → 赵县 → 洨河桥址。地图用于现代位置定位，染色前沿会随讲解逐级收拢。
- **跨河问题**：从两岸连续通行的通用需求出发，保留河流、岸线和地形的教学示意边界。
- **桥型比较**：用同一尺度对照梁、多孔拱和单孔拱，说明支点与传力方式；这部分是工程概念教学，不声称复原李春的历史决策记录。
- **逐步建构**：主拱按 28 道并列拱券逐道出现，两侧各两孔敞肩小拱随后加入，再补上拱上结构和桥面。
- **传力观察**：跟随“桥面 → 小拱 → 主拱 → 两端支承”的路径理解结构关系。箭线表达路径，不代表未经计算的应力大小或分配比例。
- **自由观察**：横向剖切、设色、结构注记、缓慢环绕和整桥复位都可在讲解结束后使用。

拖动模型、滚轮或双指会接管镜头；方向键旋转，`+` / `-` 缩放，`Home` 回到整桥。页面支持明暗主题和减少动态效果。

## 本地运行

直接打开 [index.html](index.html) 即可体验。页面已内嵌 Three.js r186.1、现代行政区地图路径和交互代码，不依赖 CDN、地图服务或运行时网络请求。

如需从源码重建入口，在仓库根目录执行：

```powershell
node build.cjs
```

构建源文件位于 [src](src/)：

| 文件 | 作用 |
| --- | --- |
| `src/layout.html` | 页面结构、样式和 UI 壳 |
| `src/player.js` | 章节状态、交互、镜头和主题控制 |
| `src/geometry.js` | 河岸、桥体、拱券和传力可视化几何 |
| `src/maps/` | 现代行政区 GeoJSON 快照及地图说明 |
| `src/vendor/` | 内嵌 Three.js 模块与许可证说明 |
| `src/sources.html` | 页面内来源弹窗内容 |

`build.cjs` 会把这些源文件和地图数据打包为可直接分享的根目录 `index.html`。

## 资料与严谨性边界

科普内容的来源核验与发布步骤见 [科普交互内容工作流](科普交互内容工作流.md)。事实台账、计算公式、来源摘录和未决问题见 [参考文档.md](参考文档.md)；科普案例研究、八段体验分镜和运镜约束见 [科普调研与体验分镜.md](科普调研与体验分镜.md)。当前页面采用的主要来源包括：

- [赵县人民政府《赵州桥》](https://www.zhaoxian.gov.cn/columns/7558c04f-250e-4c72-a91c-425e1b5a8a17/202306/26/9c718990-9c93-471a-9e27-20c31de59149.html)：年代、地点、主拱净跨、拱矢、桥面宽度、28 道拱券和小拱跨度。
- [ASCE Historic Landmarks: Zhaozhou Bridge](https://www.asce.org/about-civil-engineering/history-and-heritage/historic-landmarks/zhaozhou-bridge)：敞肩小拱的荷载路径和洪水时的过水空间解释。
- [OpenStreetMap](https://www.openstreetmap.org/#map=15/37.720229/114.763280)：现代桥址位置参考。
- [阿里云 DataV 地图数据选择器](https://datav.aliyun.com/portal/school/atlas/area_selector)：现代行政区 GeoJSON 快照，数据文件和用途说明见 [src/maps/README.md](src/maps/README.md)。
- [Three.js](https://threejs.org/)：页面内嵌的开源渲染模块，许可证见 [src/vendor/THIRD_PARTY_NOTICES.md](src/vendor/THIRD_PARTY_NOTICES.md)。

页面明确区分来源直接支持的事实、由事实推导的几何、以及为了教学呈现而设置的示意参数。地图是现代行政区定位，不是隋代行政图；逐券逐孔显现是模型拆解顺序，不是隋代施工记录。公开资料对桥梁总长存在 64.4 m 与约 50.9 m 等不同口径，页面保留这一差异，不自行推断测量边界。主拱厚度、小拱拱高、局部地形和桥面细部仍属于待核或示意范围。

## 当前状态

这是一个可交互科普原型，已检查桌面端 1440×900、1280×720 与 375px 窄屏，以及明暗主题、章节切换、构件进度、来源弹窗、剖切、设色、注记、环绕、键盘、拖动和滚轮操作。正式预览图见 [preview.png](preview.png)。实体触屏设备上的双指缩放仍建议在目标设备上复核，模型也不等同于文物测绘级复原。
